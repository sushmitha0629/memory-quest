# 🧠 Memory Quest

**Memory Quest** is a browser-based memory game designed to test and improve the player's **memory, concentration, and observation skills**.

The game presents a visual challenge where players need to remember the information shown and select the correct answer from multiple options. As the player progresses, the challenges become more engaging and require better concentration and memory.

## 🎮 About the Game

Memory Quest is designed with a simple and interactive interface so that players can focus on the gameplay without unnecessary complexity.

The main idea is simple:

**Observe → Remember → Choose → Challenge Your Memory!**

The game uses multiple-choice options to make the gameplay interactive and provides a fun way to test how well the player can remember information.

## 🚀 How to Play

1. Open the game in a web browser.
2. Observe the information presented on the screen.
3. Remember the required details.
4. Select the correct answer from the available options.
5. Continue through the challenges and try to achieve a high score.
